Bối cảnh dự án

Tôi học OOP C++ và muốn chuẩn hóa môi trường phát triển để có thể:

dùng trên nhiều máy khác nhau;
lưu toàn bộ lên GitHub;
clone về là dùng được gần như ngay;
tối thiểu hóa cài đặt và số extension;
ưu tiên nhẹ;
dùng VS Code (chuyển từ Sublime Text sang).
Cấu trúc thư mục dự kiến
Plain Text
OOP_C++/
│
├── .git/
│
├── input.txt
│
├── 00_Course Introduction.pdf
├── 01_General Programming.pdf
├── ...

├── T1_2/
│ │

│ │

│

│ └── ...

└── ...

Sau này sẽ có nhiều thư mục kiểu:

Plain Text
T1_2
T1_3
T2_1
T2_2
...

Mỗi thư mục con chứa các bài tập với nhiều file:

Plain Text
.cpp
.h
Yêu cầu chạy chương trình
Điều KHÔNG muốn

Tôi không muốn trong code phải viết:

C++
freopen(...)

hoặc

C++
ifstream fin(...)

Tôi muốn code luôn giữ nguyên:

C++
cin >> x;
Điều muốn

Khi chạy chương trình từ VS Code thì:

C++
cin

tự động đọc dữ liệu từ:

Plain Text
OOP_C++/input.txt

thông qua cơ chế redirect:

Shell
program < input.txt

tức là xử lý ở task/script/configuration bên ngoài, không sửa source code.

Yêu cầu format code

Tôi muốn dùng:

Plain Text
clang-format
 

theo style:

Plain Text
Google Style
Ưu tiên

Không muốn cài LLVM nguyên bộ nếu có thể.

Muốn cài nhẹ bằng:

Shell
pip install clang-format
Hành vi mong muốn

Khi nhấn:

Plain Text
Ctrl + S

thì:

Plain Text
clang-format
↓
format code
↓
save

tự động diễn ra.

Không muốn phải bấm format thủ công.

VS Code

Ưu tiên số extension ít nhất.

Nếu cần thì chỉ cài những extension tối thiểu.

Hãy đề xuất cấu hình tối giản nhất.

GitHub

Repository cần chứa toàn bộ cấu hình.

Ý tưởng:

Plain Text
OOP_C++/
│
├── .vscode/
├── .clang-format
├── input.txt
├── ...

để khi clone thì các cấu hình cũng được mang theo.

Mục tiêu lớn hơn

Tôi muốn repo có khả năng "bootstrap".

Kịch bản:

Shell
git clone ...

↓

mở VS Code

↓

chạy 1 file duy nhất

ví dụ:

Plain Text
setup.bat

hoặc

Plain Text
setup.ps1

↓

nó tự:

cài các extension VS Code cần thiết;
cài clang-format bằng pip;
tạo/cập nhật cấu hình cần thiết;
chuẩn bị môi trường làm việc.

Sau đó chỉ cần mở file C++ bất kỳ trong repo là dùng được.

Điều cần thiết kế

Hãy đề xuất một solution hoàn chỉnh gồm:

Cấu trúc thư mục tối ưu.
File .vscode/settings.json.
File .vscode/tasks.json.
File .clang-format.
Script bootstrap (setup.bat hoặc setup.ps1).
Cách build đúng file đang mở trong VS Code.
Cách tự tìm tất cả .cpp liên quan để compile (nếu bài có nhiều file cpp).
Cách redirect input từ:
Plain Text
${workspaceFolder}/input.txt

vào chương trình.

Danh sách extension tối thiểu.
Giải pháp hoạt động tốt trên Windows và có thể mở rộng sau này.
